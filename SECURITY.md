# Security

Stubbert stores a Jellyfin API key and, with notifications on, a Discord webhook URL. If you find a way to read
those, get past the login, or make Stubbert change something in Jellyfin it shouldn't, please report it privately.

## Reporting a vulnerability

Use **[Report a vulnerability](https://github.com/janzee22/stubbert/security/advisories/new)** on GitHub. Please
don't open a public issue for it.

Include what you found, how to reproduce it, and the Stubbert and Jellyfin versions. This is a hobby project, so
give it a few days for a first answer. Once a fix is out, the advisory is published and you're credited unless
you'd rather not be.

## Supported versions

Only the latest release gets security fixes.
